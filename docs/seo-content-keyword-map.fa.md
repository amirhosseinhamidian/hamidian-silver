# نقشه کلمات کلیدی و محتوای SEO گالری حمیدیان

این سند مرجع ثابت تولید محتوا برای Storefront است. هدف، ساخت صفحه‌های مفید و متمایز برای کاربر است؛ نه تکرار مصنوعی کلمات کلیدی.

## اصول عمومی

- هر intent اصلی فقط یک صفحه canonical و indexable داشته باشد.
- عنوان، H1، توضیح صفحه، alt تصویر و anchor text از واژه‌های طبیعی مرتبط با همان صفحه استفاده کنند.
- از تکرار یک meta title یا meta description روی چند صفحه خودداری شود.
- فیلترها و مرتب‌سازی‌ها صفحه هدف مستقل SEO نیستند و طبق route policy فعلی `noindex` می‌مانند.
- برای برندها از ادعای «نمایندگی رسمی»، «اصل برند» یا مالکیت علامت تجاری بدون مستندات استفاده نشود.
- متن محصول باید مشخصات همان کالا را توضیح دهد؛ کپی یکسان تأمین‌کننده برای چند محصول قابل قبول نیست.

## دسته‌بندی‌های فعلی

برای دسته‌های اصلی، intent پایه به شکل زیر است:

| دسته    | Intent هدف        |
| ------- | ----------------- |
| دستبند  | خرید دستبند نقره  |
| گردنبند | خرید گردنبند نقره |
| انگشتر  | خرید انگشتر نقره  |
| گوشواره | خرید گوشواره نقره |
| نیم‌ست  | خرید نیم ست نقره  |
| ست کامل | خرید ست نقره      |

برای زیر‌دسته‌هایی مثل زنانه/مردانه، modifier طبیعی به intent اضافه شود؛ مثال: «خرید انگشتر نقره زنانه».

## محصول

### نام محصول

نام باید هم قابل فهم و هم متمایز باشد. نام لوکس/توصیفی مجاز است، اما نوع محصول باید برای کاربر روشن بماند.

### توضیح کوتاه

- حداکثر ۶ تا ۷ واژه طبق سیاست محتوایی فروشگاه.
- برای کارت محصول است، نه meta description.
- نام کامل محصول را دوباره تکرار نکند.

### توضیح کامل

در صورت مرتبط بودن، این اطلاعات را طبیعی پوشش دهد:

- فرم و سبک طراحی
- جنس و عیار
- نوع نگین
- آبکاری
- رنگ
- کشور سازنده
- وزن/ابعاد
- سایز یا طول
- نوع قفل
- کاربرد یا استایل پیشنهادی
- نکات نگهداری
- محتویات بسته‌بندی

لازم نیست همه موارد برای همه محصولات نوشته شوند؛ فقط داده واقعی همان کالا.

### SEO override

`seoTitle` و `seoDescription` اختیاری‌اند. اگر fallback تولیدشده دقیق است، override لازم نیست. اگر override ثبت می‌شود باید واقعاً برای همان صفحه منحصربه‌فرد باشد.

## تصویر

- alt هر تصویر باید آنچه در همان تصویر دیده می‌شود را توصیف کند.
- برای چند نمای یک محصول alt یکسان ثبت نشود.
- نمونه‌ها:
  - «دستبند نقره ماری - نمای روبه‌رو»
  - «دستبند نقره ماری روی دست مدل»
  - «قفل دستبند نقره ماری - نمای نزدیک»
- از لیست کلمات کلیدی در alt خودداری شود.
- برای uploadهای جدید، storage filename از alt توصیفی ساخته می‌شود.
- تصویر اصلی محصول باید واضح و نماینده خود کالا باشد.

## برند

صفحه برند باید درباره کالکشن موجود در گالری توضیح بدهد. نام برند می‌تواند برای شناسایی طرح/کالکشن استفاده شود، اما متن نباید رابطه رسمی، نمایندگی یا اصالت مورد تأیید صاحب برند را بدون مدرک القا کند.

## دسته‌بندی

Description دسته فقط یک جمله عمومی مثل «انواع محصولات این دسته» نباشد. بهتر است درباره مدل‌های موجود، تفاوت‌ها، کاربرد و معیار انتخاب همان دسته توضیح بدهد.

## لینک‌سازی داخلی

ساختار هدف:

```text
Home
├── Categories
│   ├── Parent Category
│   │   ├── Child Category
│   │   └── Products
│   └── Relevant Brands
├── Brands
│   ├── Relevant Categories
│   └── Products
└── Featured / Popular Products
```

هر صفحه محصول باید حداقل از یک مسیر browse سایت قابل رسیدن باشد. Sitemap جایگزین navigation داخلی نیست.

## کنترل قبل از انتشار

```bash
pnpm content:audit
```

هشدارها باید بررسی شوند و failureها قبل از production برطرف شوند. Duplicate title/description، alt تکراری و filename عمومی تصاویر از مواردی هستند که audit گزارش می‌کند.
