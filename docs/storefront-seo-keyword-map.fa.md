# نقشه کلمات کلیدی و محتوای SEO فروشگاه

این سند نقشه intent صفحات Storefront است. هدف، تولید title و description منحصربه‌فرد و طبیعی است؛ نه
تکرار مصنوعی کلمات کلیدی. در صورت وجود `seoTitle` یا `seoDescription` اختصاصی در ادمین، مقدار
اختصاصی همیشه نسبت به fallbackهای برنامه اولویت دارد.

## نقشه صفحات

| نوع صفحه      | intent اصلی               | الگوی fallback title | الگوی description                                   | لینک‌های داخلی مهم                                 |
| ------------- | ------------------------- | -------------------- | --------------------------------------------------- | -------------------------------------------------- |
| Home          | گالری نقره / خرید نقره    | تنظیمات Home         | معرفی کوتاه فروشگاه و مزیت اصلی                     | دسته‌های منتخب، برندها، محصولات جدید/محبوب         |
| `/products`   | خرید محصولات نقره         | خرید محصولات نقره    | قیمت، مشخصات، دسته‌بندی، برند و موجودی              | دسته‌ها، برندها، همه محصولات                       |
| Category      | خرید [نام دسته]           | خرید [نام دسته]      | مدل‌های [نام دسته] نقره + قیمت/مشخصات/موجودی        | والد، زیر‌دسته، محصولات                            |
| Brand         | کالکشن [نام برند]         | کالکشن [نام برند]    | محصولات نقره کالکشن + قیمت/مشخصات/موجودی            | Hub برندها، محصولات برند                           |
| Product       | نام دقیق محصول            | نام محصول            | توضیح کوتاه؛ سپس توضیح کامل؛ سپس fallback برنامه‌ای | دسته اصلی، همه دسته‌های محصول، برند، محصولات مرتبط |
| Content pages | intent اطلاعاتی همان صفحه | مقدار اختصاصی صفحه   | خلاصه دقیق همان محتوای واقعی                        | صفحات مرتبط و مسیرهای خرید مرتبط                   |

## قواعد نوشتن

- عنوان صفحه باید مشخص و متمایز باشد. نام سایت با template سراسری اضافه می‌شود؛ آن را دوباره داخل
  عنوان اختصاصی تکرار نکنید.
- برای عنوان‌ها سقف مصنوعی «۶۰ کاراکتر» تعریف نشده است؛ متن باید کوتاه و توصیفی باشد.
- meta description باید خلاصه‌ای واقعی از همان صفحه باشد. Google ممکن است براساس query از متن خود
  صفحه snippet متفاوت بسازد.
- توضیح کوتاه محصول حداکثر ۷ واژه است.
- توضیح کامل محصول باید ویژگی واقعی، فرم طراحی، جنس، آبکاری، کاربرد، سایز/طول و نکات نگهداری مرتبط
  را توضیح دهد. از تکرار چندباره عباراتی مثل «خرید نقره» خودداری شود.
- برای برندها از عبارت‌هایی مثل «نمایندگی رسمی»، «اصل» یا «اورجینال» فقط در صورت وجود مستندات واقعی
  استفاده شود. fallback برنامه فقط از عبارت «کالکشن» استفاده می‌کند.
- Category و Brand باید description منحصربه‌فرد داشته باشند. fallback فقط شبکه ایمنی است و جای متن
  اختصاصی مهم‌ترین صفحات را نمی‌گیرد.

## تصاویر

- تصویر اصلی هر محصول باید واضح، مرتبط و بدون نوشته تبلیغاتی/واترمارک ناخواسته باشد.
- برای هر نمای متفاوت محصول alt متفاوت نوشته شود؛ مثال:
  - `دستبند نقره ماری - نمای روبه‌رو`
  - `دستبند نقره ماری روی دست مدل`
  - `قفل دستبند نقره ماری`
- alt نباید فهرستی از کلمات کلیدی باشد.
- تصویر اصلی محصولات به sitemap تصویری اضافه می‌شود و تصاویر محصول در Product structured data نیز
  استفاده می‌شوند.

## ساختار لینک داخلی

ساختار هدف:

```text
Home
├── Categories
│   └── Parent category
│       └── Child category
│           └── Product
├── Brands
│   └── Brand
│       └── Product
└── Products
    └── Product
```

Product breadcrumb از عمیق‌ترین دسته اختصاص‌یافته استفاده می‌کند. صفحات دسته به زیر‌دسته‌ها و همه
محصولات قابل crawl لینک مستقیم `<a href>` دارند. محصولات نیز به دسته‌ها، برند و محصولات مرتبط لینک
می‌دهند.

## چرخه بهبود با Search Console

پس از ایندکس‌شدن production، برای هر ۲ تا ۴ هفته:

1. Queryهای دارای impression را برای Home، Category، Brand و Product استخراج کنید.
2. queryهای هم‌معنی را گروه‌بندی کنید؛ یک صفحه را برای چند intent نامرتبط بهینه نکنید.
3. صفحاتی با impression مناسب و CTR ضعیف را از نظر title/description بازبینی کنید.
4. Queryهایی که landing page اشتباه دارند، با لینک داخلی و محتوای روشن‌تر به صفحه مناسب هدایت شوند.
5. قبل از تغییر titleهای دارای عملکرد خوب، مقدار قبلی و تاریخ تغییر ثبت شود.
