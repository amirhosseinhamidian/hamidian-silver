# اعلان سفارش برای مدیران در تلگرام و بله

این قابلیت بعد از ثبت موفق سفارش، برای هر Chat ID ثبت‌شده یک رکورد Outbox می‌سازد. ارسال در
پس‌زمینه انجام می‌شود و قطع موقت پیام‌رسان مانع ثبت سفارش مشتری نخواهد شد.

## متغیرهای محیطی API

```env
ADMIN_APP_ORIGIN=https://admin.hamidian.shop
TELEGRAM_BOT_TOKEN=
BALE_BOT_TOKEN=
ADMIN_MESSAGING_REQUEST_TIMEOUT_MS=8000
```

توکن‌ها محرمانه‌اند و فقط باید در `/etc/hamidian-silver/production.env` قرار بگیرند. آن‌ها را در
پنل، Git، لاگ یا پیام پشتیبانی وارد نکنید.

## راه‌اندازی تلگرام

1. در گفت‌وگو با `@BotFather` یک Bot بسازید و توکن آن را در `TELEGRAM_BOT_TOKEN` قرار دهید.
2. هر ادمین یا مدیر باید گفت‌وگوی خصوصی Bot را باز کند و Start را بزند.
3. پس از ارسال یک پیام به Bot، با متد `getUpdates` مقدار عددی `message.chat.id` را بخوانید.
4. در پنل مدیریت به «مدیریت سامانه ← اعلان سفارش مدیران» بروید و Chat ID را ثبت کنید.

مستندات رسمی: <https://core.telegram.org/bots/api>

## راه‌اندازی بله

1. از BotFather رسمی بله یک بازو بسازید و توکن را در `BALE_BOT_TOKEN` قرار دهید.
2. هر مدیر باید ابتدا بازو را باز کند و یک پیام برای آن بفرستد.
3. با متد `getUpdates` شناسه عددی گفت‌وگو را پیدا کنید.
4. همان شناسه را در ستون Chat ID بله پنل ثبت کنید.

API معمولی بازوی بله از آدرس `https://tapi.bale.ai/bot<TOKEN>/METHOD_NAME` استفاده می‌کند و
متد `sendMessage` پارامترهای `chat_id` و `text` را می‌پذیرد.

مستندات رسمی: <https://docs.bale.ai/>

## نکات عملیاتی

- فقط کاربری با نقش `MANAGER` می‌تواند این صفحه را ببیند یا شناسه‌ها را تغییر دهد.
- هر Chat ID در هر پیام‌رسان فقط به یک حساب مدیریتی قابل انتساب است تا پیام تکراری ارسال نشود.
- پیام شامل مشخصات مشتری و تحویل‌گیرنده، آدرس، اقلام، مبالغ، روش ارسال، یادداشت مشتری و لینک
  مستقیم جزئیات سفارش در پنل مدیریت است.
- ارسال‌های ناموفق با فاصله افزایشی حداکثر ۸ بار تلاش می‌شوند.
- حذف یک Chat ID فقط ارسال سفارش‌های بعدی را متوقف می‌کند؛ رکوردهای Outbox قبلی برای ردیابی
  عملیاتی حفظ می‌شوند.
