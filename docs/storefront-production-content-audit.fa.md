# ممیزی محتوای واقعی فروشگاه

این مرحله آخرین کنترل داده‌های قابل مشاهده برای مشتری پیش از staging است. اسکریپت خودکار، کامل و
سازگار بودن داده‌ها را بررسی می‌کند؛ اما واقعی بودن قیمت، تعداد فیزیکی کالا، مالکیت تصاویر و متن
حقوقی باید توسط مسئول مربوطه نیز تأیید شود.

## پیش‌نیازها

- migrationها با `prisma migrate deploy` اعمال شده باشند.
- `DATABASE_URL` به دیتابیس همان محیطی اشاره کند که فروشگاه از آن استفاده می‌کند.
- `MEDIA_STORAGE_ROOT` مسیر دائمی media همان محیط باشد.
- هنگام اجرای فرمان از ریشه پروژه، برای `MEDIA_STORAGE_ROOT` در staging/production مسیر مطلق
  مانند `/var/lib/hamidian-silver/media` تنظیم شود؛ مسیر نسبی فایل `.env.example` فقط برای
  توسعه محلی است.
- `MEDIA_PUBLIC_BASE_URL` نشانی عمومی media و `CONTENT_AUDIT_ORIGIN` نشانی Storefront باشد.
- Storefront و API در دسترس باشند و `SEED_DEMO_CATALOG` در production فعال نشده باشد.
- اگر Prisma Client تولید نشده است، ابتدا `pnpm db:generate` اجرا شود.

نمونه اجرا روی staging:

```bash
CONTENT_AUDIT_ORIGIN=https://staging.example.com pnpm content:audit
```

اسکریپت همه محصولات فعال، واریانت‌ها، SKUها، موجودی انبار فعال، قیمت‌ها، دسته‌بندی‌ها، برندها،
صفحات محتوایی و mediaهای استفاده‌شده را مستقیماً از دیتابیس می‌خواند. سپس وجود و اندازه فایل‌های
media را روی storage، پاسخ URL عمومی آن‌ها و تمام صفحات و لینک‌های داخلی قابل کشف را کنترل می‌کند.

اسکریپت فقط لینک‌های داخلی حاضر در HTML صفحات بررسی‌شده را کشف می‌کند؛ لینک‌های بیرونی،
لینک‌های ساخته‌شده بعد از اجرای JavaScript و درستی محتوای مقصد باید در کنترل دستی باز شوند.

وجود هر `FAILURE` باعث exit code غیرصفر می‌شود. `WARNING` مانع انتشار نیست، اما باید بررسی و در
release note ثبت شود؛ برای مثال ممکن است یک محصول عمداً ناموجود یا ایمیل پشتیبانی هنوز ثبت‌نشده
باشد.

## کنترل دستی الزامی

| حوزه             | روش تأیید                                                      | معیار پذیرش                                                   |
| ---------------- | -------------------------------------------------------------- | ------------------------------------------------------------- |
| قیمت             | تطبیق قیمت فروش و قیمت خط‌خورده هر محصول با لیست قیمت تأییدشده | مبلغ و واحد تومان دقیق است؛ تخفیف ساختگی وجود ندارد           |
| موجودی           | شمارش فیزیکی و تطبیق هر SKU با انبار اصلی                      | `onHand` و رزروها با وضعیت واقعی سازگارند                     |
| تصاویر           | مشاهده دسکتاپ و موبایل و بررسی فایل اصلی/حق استفاده            | تصویر درست، واضح، بدون واترمارک ناخواسته و دارای alt دقیق است |
| برند و دسته‌بندی | تطبیق نام، کشور، توضیح و انتساب محصولات                        | رکورد دمو، تکراری یا دسته‌بندی اشتباه وجود ندارد              |
| تماس             | تماس آزمایشی، ارسال ایمیل و باز کردن شبکه‌های اجتماعی          | نشانی، شماره‌ها و لینک‌ها واقعاً در اختیار گالری هستند        |
| قوانین           | بازبینی شرایط خرید، ارسال، مرجوعی، refund و حریم خصوصی         | متن با فرآیند عملیاتی جاری و نظر مسئول حقوقی سازگار است       |
| لینک‌ها          | مرور Header، Footer، Home، Catalog و صفحات محتوا               | هیچ 404، redirect بیرونی ناخواسته یا لینک منقضی وجود ندارد    |

تاریخ و مدرک داشته باشند.
