## طراحی و انتشار

در **کمپین ← صفحه و مجموعه** ابتدا لندینگ را ذخیره کنید. سپس در **طراحی صفحهٔ جشنواره** یکی از تم‌های بلک فرایدی، یلدا، نوروز یا مناسبت ویژه را انتخاب و رنگ‌ها، گرادیان، نقش و حرکت اسلایدها را تنظیم کنید. برای استفادهٔ مجدد، تم را با نام جدید ذخیره کنید. پنل ترتیب بخش‌ها را با کشیدن و رها کردن یا دکمه‌های بالا و پایین تغییر می‌دهد. هر بخش به‌جز فهرست کامل محصولات بازهٔ اختیاری در محدودهٔ کمپین دارد. متن، رنگ و مسیرهای مجاز به‌صورت فیلدهای مشخص اعتبارسنجی می‌شوند.

پیش‌نمایش موبایل و دسکتاپ از همان نمایشگر فروشگاه در عرض‌های ۳۹۰ و ۱۱۸۰ پیکسل استفاده می‌کند. دادهٔ پیش‌نویس از درخواست دارای مجوز پنل و فقط به پنجرهٔ پیش‌نمایش ارسال می‌شود. در لوکال، نشانی فروشگاه در پنل با `NEXT_PUBLIC_STOREFRONT_URL` قابل تنظیم است. پیش‌نویس از محصولات واقعی مجموعه استفاده می‌کند. بخش‌های وابسته به تخفیف یا سهمیه هنگام نبود پیشنهاد فعال می‌توانند خالی باشند.

هر ذخیره نسخهٔ تازه ثبت می‌کند و رسانه‌های همان نسخه برای بازگردانی حفظ می‌شوند. بازگردانی نسخهٔ قبلی یک پیش‌نویس جدید ثبت می‌کند. تأیید و زمان‌بندی از چرخهٔ فعلی کمپین انجام می‌شوند. لندینگ قبلی بدون طرح جشنواره با نمایش فعلی قابل استفاده است.

## نمایش عمومی و SEO

Hero از اسلایدشوی فعلی فروشگاه برای تصویر، GIF با تصویر ثابت جایگزین، متن و CTA استفاده می‌کند. تایمر چسبان از پایان واقعی کمپین می‌خواند. لندینگ بخش‌های مزیت، دسته، تخفیف‌های بزرگ، انتخاب مدیر، نزدیک پایان سهمیه، بودجه، پیشنهادهای زمان‌دار و مجموعه‌های مکمل، تمام محصولات و FAQ دارد. دسته‌ها از Facetهای همان مجموعه و قیمت و سهمیه از دادهٔ جاری کاتالوگ خوانده می‌شوند. سکشن‌های خودکارِ محصول از حداکثر ۴۸ محصول اول مجموعه با ترتیب تعیین‌شده نمونه می‌گیرند. هر سکشن حداکثر ۱۲ محصول نشان می‌دهد و مدیر می‌تواند اسلاگ محصولات مدنظر را برای منبع همان سکشن مشخص کند. بخش همهٔ محصولات همچنان کل مجموعه را صفحه‌بندی می‌کند.

فیلتر دسته، برند، قیمت و ترتیب در URL قرار می‌گیرد. درخواست صفحات بعدی روی سرور همان محدودهٔ کمپین را اعمال می‌کند. لینک‌های HTML صفحهٔ قبل و بعد مستقل از پیمایش خودکار در دسترس‌اند. کاربر می‌تواند پیمایش خودکار را متوقف کند یا به پایان فهرست برود. موقعیت و صفحات بارگیری‌شده برای بازگشت از صفحهٔ محصول در همان نشست پیمایش حفظ می‌شوند. فوتر از چارچوب فروشگاه می‌آید. نتیجهٔ فیلترشده `noindex` و Canonical صفحهٔ اصلی لندینگ دارد. قواعد صفحه‌بندی، وضعیت انقضا و Sitemap از CM-03 پیروی می‌کنند. کارایی روی دادهٔ نمایندهٔ تولید اندازه‌گیری نشده است.

برای تست PostgreSQL، Docker Desktop را روشن کنید. این بلوک دیتابیس آزمایشی را روی یک پورت آزاد راه می‌اندازد و در پایان کانتینر را جمع می‌کند.

```bash
(
  cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" || exit 1
  cam_x03_db="$(docker run -d --rm \
    -e POSTGRES_USER=hamidian -e POSTGRES_PASSWORD=cam_x03_local \
    -e POSTGRES_DB=hamidian_cam_x03_test -p 127.0.0.1::5432 postgres:18.6-alpine)" || exit 1
  trap 'docker stop "$cam_x03_db" >/dev/null' EXIT

  for attempt in {1..30}; do
    docker exec "$cam_x03_db" pg_isready -q -h 127.0.0.1 -U hamidian -d hamidian_cam_x03_test && break
    sleep 1
  done
  docker exec "$cam_x03_db" pg_isready -h 127.0.0.1 -U hamidian -d hamidian_cam_x03_test || exit 1
  cam_x03_address="$(docker port "$cam_x03_db" 5432/tcp)" || exit 1
  export DATABASE_URL="postgresql://hamidian:cam_x03_local@${cam_x03_address}/hamidian_cam_x03_test"
  pnpm db:generate &&
  pnpm exec prisma migrate deploy &&
  pnpm api:test:e2e --runInBand 'campaign-landing|campaign-lifecycle|campaign-quota|promotion-checkout'
)
```
