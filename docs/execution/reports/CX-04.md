## رفتار و تصمیم‌ها

- مشتری پس از ورود می‌تواند سبد را در حسابش ذخیره کند. پیش‌فرض یادآوری ۲۴ ساعت بعد از ذخیره و مهلت نگهداری ۱۴ روز است. تغییر زمان‌بندی برای ذخیره‌های بعدی محاسبه می‌شود. مدیر می‌تواند نمایش یادآوری را فوراً از صفحهٔ «رشد» خاموش کند. مشتری می‌تواند یادآوری همان سبد را پنهان یا خود سبد را حذف کند.
- یادآوری فقط در حساب و صفحهٔ اصلی مشتری واردشده نمایش داده می‌شود. بازگرداندن سبد از صفحهٔ سبد، پس از مشاهدهٔ قیمت و تعداد قبلی و فعلی و تأیید مشتری انجام می‌شود. اگر سبد فعلی کالا داشته باشد، دکمهٔ تأیید صریحاً جایگزینی را اعلام می‌کند. گزینهٔ ناموجود کنار گذاشته می‌شود و تعداد قابل خرید از موجودی انبار پیش‌فرض، از جمله اجزای بسته، محاسبه می‌شود.
- تأیید بازیابی در صورت تغییر دوبارهٔ قیمت یا موجودی، بازبینی تازه می‌خواهد. Checkout سبد بازیابی‌شده هم موجودی را دوباره کنترل می‌کند و Quote مبلغ نهایی را برای تأیید مشتری می‌گیرد. ثبت موفق سفارش، پس از رزرو موجودی، سبد متناظر را در همان تراکنش می‌بندد. اگر رزرو شکست بخورد، سبد قابل ادامه می‌ماند. انقضا از همان لحظه جلوی نمایش و بازیابی را می‌گیرد و کار زمان‌بندی‌شده، دادهٔ اقلام را دسته‌ای پاک می‌کند.
- داشبورد «رشد» در بازهٔ ۳۰روزه تعداد ذخیره، رهاشدگی، بازیابی، سفارش و پرداخت را تجمیع می‌کند. نرخ بازیابی نسبت سبدهای رهاشدهٔ بازیابی‌شده به کل سبدهای رهاشده است. اعداد به مجوز مالی و ویرایش تنظیمات به مجوز تنظیمات نیاز دارند. گزارش به هویت، اقلام، شماره یا دستگاه مشتری دسترسی نمی‌دهد. یادآوری فقط درون فروشگاه است.
- مهاجرت `20261126130000_saved_cart_recovery` افزایشی است. مسیرهای صفحات، Canonical، Robots عمومی، Sitemap و JSON-LD دست‌نخورده‌اند. پاسخ دادهٔ سبد خصوصی و بدون کش است.

## بررسی محلی

تست PostgreSQL سناریوهای حساب دیگر، پنهان کردن یادآوری، تغییر قیمت و موجودی، ثبت سفارش، جلوگیری از نمایش دوباره و انقضا را می‌سنجد. تست Storefront نمایش تفاوت و تأیید پیش از جایگزینی را می‌سنجد. بررسی رابط پنل و نمایش خانه و حساب در پذیرش دستی انجام می‌شود. تست‌ها و بیلد در این نوبت اجرا نشده‌اند.

cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" &&

در اجرای اولیهٔ مدیر پروژه، هر چهار مجموعه پیش از شروع سناریوها هنگام ساخت Prisma با خطای نبود `DATABASE_URL` متوقف شدند. مدیر پروژه موفقیت اجرای مجدد مجموعه‌های `cart-recovery`، `catalog-attributes`، `promotion-checkout` و `catalog-facets` را گزارش کرد. بلوک PostgreSQL زیر دیتابیس موقت را روی پورت آزاد راه‌اندازی می‌کند و در همان ترمینال، آدرس اتصال، مهاجرت و اجرای هر چهار مجموعه را انجام می‌دهد.

```bash
(
  cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" || exit 1

  cx04_db="$(docker run -d --rm \
    -e POSTGRES_USER=hamidian \
    -e POSTGRES_PASSWORD=cx04_e2e_local \
    -e POSTGRES_DB=hamidian_cx04_test \
    -p 127.0.0.1::5432 postgres:18.6-alpine)" || exit 1
  trap 'docker stop "$cx04_db" >/dev/null 2>&1' EXIT

  for attempt in {1..30}; do
    docker exec "$cx04_db" pg_isready -q -h 127.0.0.1 -U hamidian -d hamidian_cx04_test && break
    sleep 1
  done
  docker exec "$cx04_db" pg_isready -h 127.0.0.1 -U hamidian -d hamidian_cx04_test || exit 1

  cx04_address="$(docker port "$cx04_db" 5432/tcp)" || exit 1
  case "$cx04_address" in 127.0.0.1:[0-9]*) ;; *) exit 1 ;; esac
  export DATABASE_URL="postgresql://hamidian:cx04_e2e_local@${cx04_address}/hamidian_cx04_test?schema=public"

  pnpm db:generate &&
  pnpm exec prisma migrate deploy &&
  pnpm api:test:e2e --runInBand 'cart-recovery|catalog-attributes|promotion-checkout|catalog-facets'
)
```
