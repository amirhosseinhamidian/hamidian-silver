آماده‌سازی گزارش روی شاخهٔ `seo-fix` انجام شده است. مدیر پروژه در ۲۰۲۶-۱۱-۲۷ پاس شدن تست محلی استخراج را تأیید کرد. **پذیرش تجاری در انتظار انتشار و دادهٔ واقعی است.** تست محلی [QA-03](QA-03.md) تأیید شده است و شواهد بازیابی و بازگشت محیط مقصد برای همان مرحله بازند. اعداد نمونهٔ تست، نتیجهٔ ارزیابی فروشگاه محسوب نمی‌شوند.

## ارزیابی و تصمیم

۱. SHA منتشرشده و تاریخ و ساعت شروع هر قابلیت، نسخهٔ سیاست، دوره‌های مرجع و زمان Snapshot را ثبت کنید. شروع دورهٔ ارزیابی باید پس از فعال‌سازی واقعی باشد. برای مقایسهٔ نرخ خرید دوم، کامل بودن دوره و رسیدن هر گروه به ۷۲۰ ساعت را بررسی کنید.

۲. در بازه‌های هم‌طول، ترکیب روزهای هفته و مناسبت، سهم دستگاه و کانال، تغییر قیمت نقره و قیمت کاتالوگ، موجودی و زمان تغییر SEO را کنار اعداد ثبت کنید. دورهٔ مناسبتی را با دورهٔ مشابه بسنجید. در صورت تفاوت ترکیب یا تاریخچه، نتیجه را به عنوان مشاهدهٔ همراه با محدودیت گزارش کنید.

۳. حجم نمونه، پوشش Snapshot و Ledger، شمار بازپرداخت و موارد ریسک باز را کنار تغییر هر شاخص گزارش کنید. گزارش کمپین برای وصول منتسب و هزینهٔ رسانهٔ ثبت‌شده استفاده می‌شود. سود قطعی تا تکمیل پوشش بهای کالا و سایر هزینه‌ها نامشخص است. [تعریف شاخص‌ها و پوشش](MAR-12.md)

۴. پس از مقایسه، برای هر شاخص تصمیم «ادامه»، «بررسی بیشتر» یا «اصلاح» همراه با شاهد ثبت شود. برای داده‌های ناقص یا دورهٔ نارس، تصمیم به زمان تکمیل شواهد موکول می‌شود.

اسکریپت فقط جمع‌ها را در یک تراکنش خواندنی استخراج می‌کند. شناسهٔ مشتری و سفارش، شماره، نشانی و متن رویداد به خروجی نمی‌آیند. نشانی اتصال را در متغیر `QA04_REVIEW_DATABASE_URL` محیط تعیین کنید. نمونهٔ زیر فقط قالب چهار تاریخ را نشان می‌دهد و تاریخ واقعی بر اساس زمان انتشار انتخاب می‌شود.

## تست محلی استخراج

بلوک زیر یک PostgreSQL موقت روی پورت آزاد بالا می‌آورد و `DATABASE_URL` را در همان محیط تست تنظیم می‌کند. ابزار تست خودش دیتابیس ایزوله می‌سازد و مهاجرت‌ها را اعمال می‌کند. اگر Prisma Client را تازه تولید نکرده‌اید، ابتدا از ریشهٔ مخزن `pnpm db:generate` را اجرا کنید.

```zsh
(
  set -e
  set -o pipefail
  cd "/Users/amirhosseinhamidian/Projects/hamidian-silver"
  qa04_pg="$(docker run --rm -d -p 127.0.0.1::5432 \
    -e POSTGRES_USER=qa04 -e POSTGRES_PASSWORD=qa04_test_only \
    -e POSTGRES_DB=hamidian_qa04 postgres:18.6-alpine)"
  trap 'docker stop "$qa04_pg" >/dev/null || true' EXIT
  for qa04_attempt in $(seq 1 60); do
    if docker exec "$qa04_pg" pg_isready -q -h 127.0.0.1 -U qa04 -d hamidian_qa04; then
      break
    fi
    sleep 1
  done
  docker exec "$qa04_pg" pg_isready -h 127.0.0.1 -U qa04 -d hamidian_qa04
  qa04_port="$(docker port "$qa04_pg" 5432/tcp | awk -F: 'NR == 1 {print $NF}')"
  test -n "$qa04_port"
  export DATABASE_URL="postgresql://qa04:qa04_test_only@127.0.0.1:${qa04_port}/hamidian_qa04?schema=public"
  pnpm api:test:e2e --runInBand --runTestsByPath test/growth-review.e2e-spec.ts
)
```

اجرای اول به‌دلیل نبود `DATABASE_URL` پیش از اتصال به PostgreSQL متوقف شد. مدیر پروژه پاس شدن اجرای مجدد را اعلام کرد. تست، حذف خرید کاملاً مرجوع‌شده، محاسبهٔ نرخ و زمان خرید دوم، نرخ مصرف و انقضا، حفظ مقدار ناموجود برای Quote ناقص و حذف شناسه‌ها از خروجی را می‌سنجد.
