# PD-05 — سئوی Facetها و کنترل کیفیت انتشار

وضعیت `IN_REVIEW` است. کار از `b0938b4` روی `seo-fix` آغاز شد و کامیت `96b191886a34a46be829759922838bee94d9b23f` روی همان شاخه تأیید شد. SEO-01 پذیرفته شده است. شواهد PostgreSQL مربوط به PD-01 و PD-02 و بررسی پس از انتشار SEO-02 در انتظار ثبت‌اند.

## سیاست مسیر

| درخواست | پاسخ و تصمیم |
| --- | --- |
| فهرست، دسته یا برند تمیز و دارای محصول | پاسخ ۲۰۰، Index/Follow و Canonical خودارجاع یا مسیر معتبر تنظیم‌شده در پنل |
| `?page=2` روی یک صفحهٔ موجود | پاسخ ۲۰۰، Canonical شامل شمارهٔ صفحه و لینک HTML به صفحهٔ بعد در صورت وجود. تنظیم Canonical خودارجاع در پنل شمارهٔ صفحه را حفظ می‌کند. |
| Facet، جست‌وجو، Sort یا پارامتر ناشناخته حتی با مقدار خالی | Noindex/Follow و Canonical صفحهٔ پایه. لینک صفحهٔ بعد در فهرست تعاملی فیلترشده یا مرتب‌شده `rel="nofollow"` دارد. |
| UTM روی صفحهٔ دوم تمیز | Noindex/Follow و Canonical همان صفحهٔ دوم بدون UTM |
| `?page=1`، مقدار خالی، غیرمعمول یا تکراری | فهرست صفحهٔ اول، Noindex/Follow و Canonical صفحهٔ پایه |
| صفحهٔ تمیز خارج از نتایج، یا هر شماره بیشتر از ۱۰۰۰ | صفحهٔ خطای ۴۰۴ بدون Canonical و با Noindex. اگر Next پاسخ را پیش‌تر استریم کرده باشد، HTTP ممکن است ۲۰۰ بماند و HTML نشانگر ۴۰۴ داشته باشد. شمارهٔ بالاتر از سقف پیش از درخواست نتایج رد می‌شود. |
| صفحهٔ دوم یا بالاترِ بدون نتیجه، درون سقف و با Facet یا Sort | راه بازگشت به صفحهٔ اول نتایج، Noindex/Follow و Canonical صفحهٔ پایه |
| محصول منتشرشدهٔ ناموجود | مسیر محصول پاسخ ۲۰۰ و Canonical خودش را دارد، تابع تنظیم SEO رکورد است و در صورت داشتن قیمت، Offer از `OutOfStock` استفاده می‌کند. |

فیلترها در URL خروجی با ترتیب ثابت کلید، کد ویژگی و گزینه‌ها تولید می‌شوند. گزینه‌های تکراری حذف می‌شوند. سقف فعلی ۱۶ مقدار متمایز برای هر گروه، ۸ ویژگی و ۱۰۰۰ صفحه حفظ شده است. درخواست شماره‌صفحهٔ نامعتبر به BFF فیلتر پاسخ ۴۰۰ با هدر `X-Robots-Tag` می‌دهد. مسیرهای پارامتردار از Sitemap وارد چرخهٔ کشف نمی‌شوند. سازندهٔ Sitemap از رکوردهای فعال و مسیرهای بدون Query استفاده می‌کند و دسته یا برند خالی را کنار می‌گذارد. Googlebot می‌تواند HTML فیلتر را بخواند و `noindex` را ببیند. `nofollow` روی پیوند صفحه‌بندی مکمل این سیاست است. [راهنمای صفحه‌بندی گوگل](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading) · [راهنمای Facet](https://developers.google.com/crawling/docs/faceted-navigation) · [راهنمای Noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing)

## زیردسته‌های پیشنهادی برای بررسی انتشار

ساختار دستهٔ CAT-02 مسیر پایدار، انتساب محصول و Breadcrumb را فراهم می‌کند. نام، توضیح و عنوان SEO هر صفحه از فیلدهای همان دسته در پنل می‌آیند. آزمون مرورگر روی دادهٔ نمونه، متن مستقل، پیوند HTML از والد، Canonical، BreadcrumbList و عضویت Sitemap را با هم بررسی می‌کند. [گزارش ساختار دسته‌ها](CAT-02.md)

| مسیر کاندید | عنوان پیشنهادی | متن معرفی پیشنهادی برای پنل |
| --- | --- | --- |
| `/categories/bracelets-chain` | دستبند زنجیری نقره | هنگام انتخاب دستبند زنجیری، مدل بافت، عرض زنجیر و نوع قفل را مقایسه کنید. طول دستبند را با دور مچ بسنجید و برای مدل‌های تنظیم‌شونده، بیشترین و کمترین طول را در مشخصات محصول ببینید. |
| `/categories/bracelets-cuff` | دستبند کاف نقره | برای انتخاب دستبند کاف، ابعاد دهانه، عرض بدنه و اندازهٔ مچ را بررسی کنید. اگر مدل پهن می‌خواهید، اندازهٔ بدنه را هم در کنار دهانه مقایسه کنید تا فرم آن روی مچ مطابق سلیقه‌تان باشد. |
| `/categories/bracelets-plate` | دستبند پلاک‌دار نقره | در دستبند پلاک‌دار، اندازه و شکل پلاک در کنار عرض بند یا زنجیر روی ظاهر دستبند اثر دارد. عکس نزدیک و اندازه‌های هر مدل را ببینید و نوع قفل و طول دستبند را با نیازتان تطبیق دهید. |

برای انتخاب کاندید، از Search Console ملک `hamidian.shop`، بخش Performance و Search results، نوع Web و بازهٔ سه ماه اخیر، خروجی Queries با ستون‌های Query، Impressions و Clicks لازم است. عبارت‌های فارسی و معادل‌های رایج هر سه نوع دستبند را در خروجی نگه دارید. پس از تأیید تقاضا و انتساب محصولات فعال، والد `bracelets` و اسلاگ پایدار را در پنل بررسی کنید. در محیط بازبینی، متن تأییدشده را در توضیح دسته بگذارید و Canonical خودارجاع، Breadcrumb، پیوند والد و حضور دستهٔ فعال در Sitemap را کنترل کنید. شاهد تقاضا و فعال‌سازی در سایت در انتظار تصمیم انتشار است.

pnpm storefront:lint && pnpm storefront:typecheck && pnpm storefront:test &&
pnpm storefront:test:e2e catalog-seo.spec.ts catalog-facets.spec.ts category-hierarchy.spec.ts guide-seo.spec.ts

| کنترل نمونه در Playwright | نتیجهٔ مورد انتظار |
| --- | --- |
| `/categories/rings` → `/categories/women-rings` | لینک HTML پایدار، متن معرفی مستقل، Canonical خودارجاع، Index/Follow و BreadcrumbList شامل والد و فرزند |
| `/brands/sample?page=2` | صفحهٔ دوم با Canonical همان صفحه، حتی با Canonical خودارجاع تنظیم‌شده برای برند |
| `/categories/rings?sort=featured&page=2` و `?page=2&page=2` | Noindex/Follow و Canonical تمیز |
| `/products?sort=featured&page=1001` و `/api/catalog/facets?page=1&page=2` | خطای صفحه بدون Canonical، و پاسخ ۴۰۰ با X-Robots-Tag در BFF |
| `/products/sold-out-ring`، `/robots.txt` و `/sitemap.xml` | محصول ناموجود با Offer صحیح و قابل کشف، اعلام Sitemap و عضویت صفحات تمیز بدون Query |

مدیر پروژه موفقیت تست‌های دستی Storefront را تأیید کرد. نتیجهٔ بیلد در انتظار ثبت است. برای پذیرش انتشار، پیش‌نیازهای باز و URLهای نمونهٔ SEO-01 و SEO-02 در محیط تأییدشده باید بررسی شوند.
