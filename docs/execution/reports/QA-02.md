وضعیت **DONE** روی شاخهٔ `seo-fix` است. مدیر پروژه در ۲۰۲۶-۱۱-۲۷ پاس شدن تست‌های محلی QA-02 را اعلام کرد و ادامه به QA-03 را تأیید کرد. SHA، عدد اندازه‌گیری کاتالوگ و فایل Trace جداگانه ثبت نشده‌اند. نتیجه‌ای از CI برای این مرحله ثبت نشده است.

## اصلاح رفتار پرداخت

تأیید دیرهنگام درگاه بعد از آزادسازی رزرو و انقضای سفارش می‌تواند به تطبیق مالی نیاز داشته باشد. صفحهٔ نتیجه اکنون هنگام `RECONCILIATION_REQUIRED` وضعیت «در حال بررسی» را نشان می‌دهد. جزئیات سفارش هم همان هشدار را می‌دهد و اقدام پرداخت مجدد در این وضعیت نمایش داده نمی‌شود. پیام ثبت رسید به وضعیت «در انتظار بررسی» از پاسخ سفارش وابسته است.

تغییر فروشگاه در محتوای صفحات موجود نتیجهٔ پرداخت و جزئیات سفارش است. مسیر، HTTP و لینک‌های ناوبری فعلی، Canonical، Robots، Sitemap و JSON-LD به همان قرارداد ادامه می‌دهند. Playwright وجود `noindex` را روی نتیجهٔ پرداخت بررسی می‌کند.

## اجرای لوکال

دستور زیر PostgreSQL موقت را با پورت آزاد راه‌اندازی می‌کند. آن را در محیط تست اجرا کنید.

```zsh
(
  set -e
  set -o pipefail
  cd "/Users/amirhosseinhamidian/Projects/hamidian-silver"
  qa02_pg="$(docker run --rm -d -p 127.0.0.1::5432 \
    -e POSTGRES_USER=qa02 -e POSTGRES_PASSWORD=qa02_test_only \
    -e POSTGRES_DB=hamidian_qa02 postgres:18.6-alpine)"
  trap 'docker stop "$qa02_pg" >/dev/null || true' EXIT
  for qa02_attempt in $(seq 1 60); do
    if docker exec "$qa02_pg" pg_isready -q -h 127.0.0.1 -U qa02 -d hamidian_qa02; then
      break
    fi
    sleep 1
  done
  docker exec "$qa02_pg" pg_isready -h 127.0.0.1 -U qa02 -d hamidian_qa02
  qa02_port="$(docker port "$qa02_pg" 5432/tcp | awk -F: 'NR == 1 {print $NF}')"
  test -n "$qa02_port"
  export DATABASE_URL="postgresql://qa02:qa02_test_only@127.0.0.1:${qa02_port}/hamidian_qa02?schema=public"
  export OTP_PEPPER='qa02-local-test-only-pepper-123456'
  export SMS_PROVIDER=disabled PAYMENT_PROVIDER=disabled SHIPPING_PROVIDER=disabled
  export STOCK_NOTIFICATIONS_ENABLED=false SEARCH_CONSOLE_SYNC_ENABLED=false
  export TELEGRAM_BOT_TOKEN='' TELEGRAM_RELAY_URL='' TELEGRAM_RELAY_SECRET='' BALE_BOT_TOKEN=''

  pnpm db:generate
  pnpm db:validate
  pnpm exec prisma migrate deploy
  pnpm contracts:typecheck
  pnpm api:typecheck
  pnpm api:lint
  pnpm frontend:lint
  pnpm frontend:typecheck
  pnpm test:critical
  pnpm api:test --runInBand 'modules/(audit|auth|authorization|campaigns|catalog|promotions|reward-policies|referrals|wallet)'
  pnpm admin:test src/proxy.test.ts
  pnpm storefront:test src/lib/checkout/verified-payment-status.test.ts src/components/checkout/payment-result.test.tsx
  pnpm api:test:e2e --runInBand 'policy-simulation|campaign-(list|lifecycle|quota|landing|operations)|catalog-(facets|search|ranking)|purchase-reward-jobs|promotion-checkout|referral|wallet'
)
```

هر سه اندازهٔ Playwright از تنظیمات مخزن استفاده می‌کنند. Trace ویدئو و تصویر شکست کنار گزارش Playwright تولید می‌شوند. برای نگهداری Trace مرحله‌های اصلی در اجرای موفق، این بلوک Trace را روشن می‌کند.

```zsh
cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" &&
pnpm storefront:test:e2e purchase-flow.spec.ts wallet.spec.ts referrals.spec.ts catalog-facets.spec.ts gift-finder.spec.ts campaign-landing.spec.ts festival-preview.spec.ts --trace on
```
