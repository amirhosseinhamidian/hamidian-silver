## رفتار

- جست‌وجوی نام، شناسهٔ محصول، SKU و اسلاگ و فیلتر دسته، برند و موجودی در سرور اجرا می‌شود. جست‌وجو از نرمال‌سازی فارسی فعلی کاتالوگ استفاده می‌کند و نتیجه هر بار حداکثر ۱۲ محصول دارد. هنگام جست‌وجوی عادی و بازخوانی انتخاب‌ها، موجودی از واریانت‌ها و اجزای بستهٔ همان محصولات خوانده می‌شود. در فیلتر موجودی، پیش از صفحه‌بندی وضعیت نامزدهای فیلترشده محاسبه می‌شود. پنل جست‌وجو را با مکث کوتاه اجرا می‌کند و درخواست‌های قدیمی را لغو می‌کند. نام، تصویر، قیمت پیش‌فرض، موجودی انبار پرداخت و دسته نمایش داده می‌شوند. فهرست انتخاب‌ها مستقل از صفحهٔ نتایج است و حذف و انتخاب بدون تکرار دارد.
- در فرم دامنه، فهرست ثابت و دسته‌های مستقیم به‌صورت جدا ذخیره می‌شوند. در این فرم انتخاب دستهٔ مادر فقط عضویت مستقیم را شامل می‌شود. در قواعد پویا، دستهٔ مادر زیرمجموعه‌های فعال را هم پوشش می‌دهد. پنل مسیر دسته، شمار محصولات فعال و پیش‌نمایش تصویری صفحه‌بندی‌شدهٔ هر دسته را نشان می‌دهد. دامنهٔ مالی و مجموعه با شناسهٔ یکتای محصول محاسبه می‌شوند.
- در لندینگ، مدیر بین مجموعهٔ پویا و فهرست ثابت انتخاب می‌کند. انتخاب برند و دسته جست‌وجو و پیش‌نمایش تصویری محصول دارد. فهرست مجموعه‌های هوشمند ذخیره‌شده قابل جست‌وجو و صفحه‌بندی است. قواعد مجموعهٔ انتخابی در پیش‌نویس حاضر کپی می‌شوند و همچنان محصولات دامنهٔ جشنوارهٔ جاری را بر اساس کاتالوگ زنده تعیین می‌کنند. پیش‌نمایش لندینگ تعداد محصولات مطابق کل قواعد را با API فعلی نشان می‌دهد.
- انتخابگر در بستهٔ تخفیف، منابع سکشن، پیش‌نمایش قیمت و واریانت‌ها و تنظیم سهمیه نیز استفاده می‌شود. قیمت جشنواره در انتخابگر، پیش‌نمایش تخفیف قطعی قیمت پیش‌فرض بر اساس قانون ذخیره‌شدهٔ همان کمپین است. ماندهٔ سهمیه از دادهٔ رزرو، فروش و فروش دستی خوانده می‌شود. برای دیدن قیمت مستقل هر واریانت، پیش‌نمایش قیمت موجود در تب قانون و کوپن به کار می‌رود. سهمیه در مدل فعلی سطح محصول دارد.
- API انتخابگر تحت مجوز خواندن تنظیمات در پنل است. مسیرها و دادهٔ عمومی فروشگاه و قراردادهای SEO از همان موتور لندینگ قبلی عبور می‌کنند. این مرحله مهاجرت تازه‌ای ندارد.

## بررسی محلی

تست رابط، ماندن انتخاب‌ها بین صفحه‌ها، حذف و جلوگیری از تکرار را بررسی می‌کند. E2E پایگاه داده جست‌وجوی SKU، تصویر و قیمت پیش‌فرض، دستهٔ مستقیم و درختی، برند، موجودی انبار پرداخت، شمار دسته، خواندن مجموعهٔ قابل کپی و مرز صفحه‌بندی ۱۳ محصول را می‌سنجد. سنجش زمان پاسخ روی کاتالوگ نمایندهٔ تولید نیازمند اجرای محلی جداگانه است.

```bash
cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" &&
DATABASE_URL='postgresql://schema:schema@127.0.0.1:5432/schema' pnpm contracts:generate &&
pnpm contracts:typecheck &&
pnpm api:lint &&
pnpm api:typecheck &&
pnpm api:test --runInBand modules/campaigns modules/catalog modules/promotions modules/authorization &&
pnpm admin:lint &&
pnpm admin:typecheck &&
pnpm admin:test campaign-product-search critical-operations-bff
```

```bash
(
  cd "/Users/amirhosseinhamidian/Projects/hamidian-silver" || exit 1
  fest05_db="$(docker run -d --rm \
    -e POSTGRES_USER=hamidian -e POSTGRES_PASSWORD=fest05_local \
    -e POSTGRES_DB=hamidian_fest05_test -p 127.0.0.1::5432 postgres:18.6-alpine)" || exit 1
  trap 'docker stop "$fest05_db" >/dev/null' EXIT
  for attempt in {1..30}; do
    docker exec "$fest05_db" pg_isready -q -h 127.0.0.1 -U hamidian -d hamidian_fest05_test && break
    sleep 1
  done
  docker exec "$fest05_db" pg_isready -h 127.0.0.1 -U hamidian -d hamidian_fest05_test || exit 1
  fest05_address="$(docker port "$fest05_db" 5432/tcp)" || exit 1
  export DATABASE_URL="postgresql://hamidian:fest05_local@${fest05_address}/hamidian_fest05_test"
  pnpm exec prisma migrate deploy &&
  pnpm api:test:e2e --runInBand 'campaign-landing|campaign-operations|catalog-facets|campaign-quota|promotion-checkout'
)
```

در بازبینی دستی پنل، یک جشنوارهٔ پیش‌نویس را باز کنید، محصولی را با SKU و فیلتر موجودی پیدا کنید و انتخاب‌های دو صفحه را ذخیره و بازخوانی کنید. در تب صفحه و مجموعه، دستهٔ مادر، برند و یک مجموعهٔ هوشمند را انتخاب کنید و پیش‌نمایش و بازخوانی را بررسی کنید.

مدیر پروژه موفقیت تست‌های محلی را گزارش کرد و قراردادهای تولیدشده در کامیت موجودند. نتیجهٔ بازبینی دستی پنل و سنجش زمان پاسخ روی کاتالوگ پرتعداد هنوز ثبت نشده‌اند.
