# MAR-08 | فرم‌های کمپین و اعتبارسنجی فیلدها

وضعیت **IN_REVIEW** روی شاخهٔ `seo-fix` است. پاس شدن تست‌های لوکال MAR-07 را مدیر پروژه تأیید کرد. [گزارش MAR-07](MAR-07.md)

فرم‌های جشنواره، پیشنهاد فروش و بازاریابی ترتیب تاریخ، مبلغ و فیلدهای الزامی را پیش از ارسال بررسی می‌کنند. خطاهای قابل رفع کنار ورودی مربوط با پیام فارسی نمایش داده می‌شوند و فوکوس به آن برمی‌گردد. پیام‌های شناخته‌شدهٔ API برای مقصد، هزینهٔ کانال، کوپن و سقف سهمیه به همان فیلد می‌رسند. اگر ورودی در مرحلهٔ فعلی در دسترس نباشد، پیام در فرم نمایش داده می‌شود. مقادیر واردشده برای اصلاح بعد از خطا در فرم می‌مانند.

فیلدهای مالی این گردش مبلغ صحیح تومان می‌گیرند. هنگام تایپ، مبلغ بدون جداکننده قابل ویرایش است و با خروج از فیلد دسته‌بندی می‌شود. اعشار یا علامت منفی برای اصلاح در ورودی می‌مانند و به مقدار دیگری تبدیل نمی‌شوند. درصد قانون و سقف درصد تا دو رقم اعشار و در بازهٔ قرارداد API نمایش داده می‌شوند. نرخ‌های اختصاصی جشنواره بازهٔ جداگانهٔ ۱ تا ۵۰ درصد را دارند. راهنمای فرم اثر صفر یا خالی را برای بودجه، حداقل خرید، سقف تعداد استفاده و فروش دستی توضیح می‌دهد. API هنگام ذخیرهٔ سهمیه فروش قطعی و رزروهای جاری را بررسی می‌کند.

بخش پایانی نشانی جشنواره و اولویت قانون در «تنظیمات پیشرفته» در دسترس‌اند. خالی گذاشتن نشانی، مقدار خودکار می‌سازد. ذخیرهٔ پیش‌نویس جشنواره به انتخاب محصول می‌رسد و ادامهٔ پیش‌نویس از فهرست در مسیر فعلی باقی است. قرارداد ثبت، نسخه‌بندی و محاسبهٔ تخفیف در API مبنای اعتبارسنجی است.
